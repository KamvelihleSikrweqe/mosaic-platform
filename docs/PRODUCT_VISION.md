# MOSAIC product vision

## Category
Programmable business infrastructure: an environment in which each organisation can compose, customise, develop, deploy and govern its own business applications.

## Product pillars
1. Organisation control plane: tenants, teams, roles, environments, policy and lifecycle.
2. Organisation runtime: metadata, application execution, workflows, events and audit.
3. Developer platform: CLI, SDKs, API catalogue, local development, testing and Git-based releases.
4. Studios: application, developer, infrastructure and AI development experiences.
5. Marketplace: installable applications, connectors, templates, agents and managed services.

## Product principles
- Full-code and visual development are equally supported.
- Tenant isolation is a security invariant, not a UI feature.
- Open standards and portable deployments; avoid cloud lock-in.
- AI is optional and replaceable; deterministic policy and human approval govern consequential actions.
- Extensibility through versioned APIs and signed packages.
- Self-hosted, private-cloud, public-cloud and hybrid deployment targets.

## Initial wedge
Supplier identity, onboarding, procurement workflow and invoice coordination as the first reference application. Validate with prospective customers before treating it as the definitive market entry point.

## Non-goals for v0.1
- Replacing ERP, CRM, core banking or cloud providers.
- Running arbitrary customer code in the control plane.
- Handling real payments or holding customer funds.
- Claiming regulatory compliance or production-grade security.
