# Contributing

MOSAIC is in an early design and prototype phase. Contributions that improve security, architecture clarity, developer experience, tests, and documentation are especially welcome.

## Before contributing
- Open an issue to discuss significant changes.
- Keep changes focused and documented.
- Add tests for changed behaviour.
- Never commit credentials, personal data, customer information, or employer-confidential material.
- Do not add arbitrary code execution to the workflow/runtime without a documented threat model and security review.

## Development
The initial prototype uses Python and FastAPI. See the README for its current status and local setup. The prototype is not production-ready.

## Pull requests
Describe the problem, approach, tests run, security implications, and any migration or compatibility impact.
